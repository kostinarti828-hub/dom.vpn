# Dom.VPN Telegram bot

Telegram Mini App Dom.VPN с тарифами на 1, 3, 6 и 12 месяцев. Mini App показывает цены из конфигурации бота и передаёт выбранный тариф обратно в чат. Бот запрашивает телефон и отправляет заявку менеджеру. Оплата и выдача VPN-доступа пока выполняются менеджером вручную.

## Запуск в Windows

Требуется Node.js 20 или новее. Бот и Mini App-сервер запускаются одним процессом; Express раздаёт страницу и каталог `/api/plans`.

1. Установите бота и Mini App-сервер на хостинг с публичным HTTPS-доменом. Telegram не открывает Mini App с локального адреса `localhost` или обычного HTTP.
2. В `.env` задайте `WEB_APP_URL=https://ваш-домен/` и `TELEGRAM_BOT_TOKEN`. URL должен вести на этот же сервер; он отдаёт Mini App и API цен. Настройте хостинг на запуск `npm start` и передачу переменной `PORT` (по умолчанию `3000`).
3. Запустите бота, откройте его в Telegram от имени менеджера и отправьте `/start`, затем `/id`. Впишите показанный ID в `ADMIN_CHAT_ID` и перезапустите бота. Telegram не разрешает боту первым начинать личный диалог.
4. Цены по умолчанию: 100, 300, 600 и 1200 рублей. При необходимости измените `PRICE_1M`, `PRICE_3M`, `PRICE_6M`, `PRICE_12M`; можно также задать `SUPPORT_USERNAME` без символа `@`.
5. В папке `telegram-bot` выполните:

   ```powershell
   npm install
   npm start
   ```

Покупатель отправляет `/start`, нажимает reply-кнопку «Открыть магазин», выбирает тариф и нажимает «Заказать». Mini App передаёт в бот только ID тарифа; цену бот берёт из своей конфигурации. Затем бот просит поделиться номером через встроенную кнопку контакта и пересылает заявку менеджеру. Команда `/cancel` отменяет незавершённую заявку.

Этот проект пока не принимает платежи и не создаёт VPN-конфигурации автоматически. Для полного цикла покупки понадобятся платёжная интеграция и API VPN-сервера/провайдера, который создаёт клиентские конфигурации или ссылки подписки.
